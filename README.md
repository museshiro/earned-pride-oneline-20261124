One line of earned pride — a small person, a long effort, finally landing.

> "My mother mopped that hospital floor for nine years; this morning she signed the deed to the house she cleaned before every shift."

`main.ts` (Node 22, standard library only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` when the variable is unset. It throws if the line is over 240 characters, and it is deterministic: two runs produce byte-identical output.
